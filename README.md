[The GPS Swears It Was a Shortcut](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)
([bounty page](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)).

The GPS's own excuse for sending the driver down the wrong road (161 characters, under the 200 limit): it opens "in my defence", blames the map's "shortcut", and drove into a lake, a wedding, and one territorial goose — then hides behind a smug technicality in the last line.

`main.py` (Python 3, standard library only) copies `entry.txt` to `/output/entry.txt`:

> In my defence, the map said shortcut and I believed it — the lake, the wedding, and the goose were never on my screen. I promised faster. I never promised drier.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
